MANUAL DE CAMPO

Controlos

Toca: seleciona uma unidade, depois toca no terreno para a mover, num inimigo para atacar ou num cristal para extrair com operários.
Arrasta com um dedo: desloca o mapa. Junta ou afasta dois dedos: altera o zoom. Usa o minimapa para deslocação rápida.
Botões Base / Operário / Exército: seleção rápida. Atacar: ordem ofensiva. Cancelar: sai de um modo de comando.
Clique esquerdo / arrastar: selecionar unidades. Shift: acrescentar à seleção.
Clique direito: mover, atacar inimigos ou recolher recursos com operários.
WASD / setas: deslocar câmara. Roda: zoom. Espaço: voltar à base.
1–3: selecionar grupos. Ctrl+1–3: guardar a seleção num grupo.
H: selecionar núcleo. F1: selecionar exército. Esc: cancelar ordem.

Começa por selecionar um operário para erguer edifícios. Seleciona o quartel para treinar soldados. Constrói um relé para aumentar a população máxima. Os operários regressam automaticamente à mineração.
